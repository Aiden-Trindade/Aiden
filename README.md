# Aiden Trindade · Portfolio

Personal portfolio built with Next.js, React and TypeScript, exported as a static site.

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Build

```bash
npm run build
```

The static site is written to `out/`, ready for GitHub Pages or Vercel.

## Editing content

Projects, skills, achievements and links live in `data/content.ts`. Page layout is in `app/page.tsx` and styles in `app/globals.css`.
